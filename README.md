# diphyx/homebrew-tap

Homebrew formulas for [diphyx](https://github.com/diphyx) tools.

```bash
brew install diphyx/tap/grid
brew install diphyx/tap/shipo
```

| Formula | Description                                                       | Project                                         |
| ------- | ----------------------------------------------------------------- | ----------------------------------------------- |
| `grid`  | Send jobs to machines you control, and get the results back       | [diphyx/grid](https://github.com/diphyx/grid)   |
| `shipo` | Bump, tag, build and publish any repo from a few lines of config  | [diphyx/shipo](https://github.com/diphyx/shipo) |

The formulas are written by each project's release workflow; do not edit them by hand.
